The page the crawl starts from. It stays inside that site.

The folder the settings file and every build go in, as a full path. It is created if it does not exist. The suggested one is a folder named Extractium under your home folder, rather than Documents, which some computers copy to a cloud drive.

The terminal does the same with this command, run in that folder:

extractium init

The file switches on three outputs: the compressed search index, the llms.txt files, and the Markdown folder the page shows results from. The documentation for this page explains each one.
